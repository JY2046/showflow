Try the five-minute workflow

  1. Open ShowFlow and click Try English sample. The synthetic two-slide PPTX becomes active; the prior project and original are retained in this browser. Your own PPTX can contain up to 30 slides / 30 MB.
  2. Search the live catalog with Front. Current all-term matches, partial matches and history are separate, with no automatic AI selection. The catalog contains company/title/year/round metadata only. For detailed industry queries, use the labeled external PDF/PPT links: the complete query is retained, and you save useful links manually. These are not readings of whole external decks.
  3. Open Styles, set a global theme, then change one slide. Export editable PowerPoint and compare it with the preserved original.
  4. Open Director, start rehearsal, pause, flag a slide, advance, finish and review actual timing. Export your cue cards.
  5. Reload to confirm project and style persistence. Rehearsal/Q&A state is session-only; each browser and origin has separate storage.

Review real device AI

Open the historical sanitized run from November 17. It records actual SDK ON_DEVICE sources and App Check, including one suggestion rejected for unsupported wording. This is a prior local run, not a new response from this preview.

For fresh inference, clone the public source and follow its README. Configure your own Firebase web app and App Check locally, prepare the supported Chrome device model, inspect the selected text, consent and generate. No shared debug credential or production project key is provided.

Privacy and limitations

Original PPTX bytes and images remain browser-local in this implementation. Notes are excluded from model input by default. Cloud processing requires explicit scope approval. Imports are content previews: fonts, masters, diagrams and animations may differ from PowerPoint. Keep the original. On-device setup and attestation may need a network connection; complete offline loading is untested.

Cloud activation will be validated after usable quota arrives. No successful cloud handoff is claimed. Temporary hackathon accounts, if approved, do not provide a durable judging backend by themselves.
